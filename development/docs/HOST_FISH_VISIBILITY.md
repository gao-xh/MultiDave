# 员工附近的鱼避让

当前0.1.48-dev与allocator/LOD共用[房主员工实际身体窗口](HOST_BODY_FISH_INTEREST.md)；合作模式不借客户端姿态或失源回退。以下保留0.1.43的有限正交镜头/原false补充范围，实际原生避让与双游戏效果仍未验证。

0.1.43-dev、协议8扩展默认关闭的 `Network.ExperimentalHostFishAreas`。
0.1.42已接普通生成器和中央LOD；本轮补的是部分自然鱼更新中
`Renderer.isVisible` 对原避让请求的镜头限制。原生执行、全部鱼行为和双机远距离仍待验证。

## 实际接线

`NativeHostFishVisibilityArea` 关联原 `SABaseFishSystem.Update_Imple` 同步范围，
只接受这条鱼直接持有的 `_fishBodyRenderer` 的原 `get_isVisible` 返回。
原结果为true时保持；原false才检查员工区域。它不修改真实renderer的可见性字段，
不直接调用一次额外AI更新、伤害或捕获。原更新中的捕获条件、请求和后续处理仍由游戏执行。

来源沿用实际接收帧绑定的房间、成员、序号、场景和房主接收时间，
持续核对本地玩家与Unity场景。显示插值位置、Local test和远端时间不提供此来源，
暂停、换层、断线、来源过期或失效时保留原结果。

## 员工区域几何

只支持同平面、实际正交 `Camera.main` 的窄范围。读取真实renderer bounds，
按房主位置减员工观察位置平移其八个角，再使用同一实际镜头的 `WorldToViewportPoint`。
八角均在带内缩余量的视口和near/far深度内才接受；部分越界、非有限值、
不同平面、未知镜头或来源变化保持原结果。

坐标在binary32输入的double平移后向外取整，避免大坐标抵消把实际鱼边界缩成一点。
该几何没有复用LOD的0.61/0.65迟滞范围。它只是一项保守员工区域候选，
不等同Unity所有相机、阴影或其他可见性判断，也不证明实际客机镜头尺寸相同。

## 生命周期与边界

只在已经确认的Unity线程读取原生对象；其他线程、范围外renderer和未知对象保留原行为。
自然范围按嵌套与原调用退出维护，不把另一条鱼或另一次调用的结果复用到当前鱼。
来源本身读取及适配器自己的几何读取不作为原鱼的可见性查询。
原执行被其他挂钩跳过、抛出异常或身份改变时不提升结果。

挂钩和原生包装器ABI、真实回调顺序、其他Mod顺序以及完整鱼类型覆盖未验证。
同步包含本身不是完整原生直接调用链证明。失败后停止本模块的补充，
保留原鱼运行逻辑；活动调用中的挂钩不热卸载。来源及同步范围读数的实际开销尚未测量。

鱼还需已经生成、保持活动并通过资源解析，客机才有内容可显示。
本入口不加载另一层，不创建可信员工角色，不提供命中或背包权限。
客户端显示和房主双区域分别见 [HOST_FISH_INTEREST](HOST_FISH_INTEREST.md)；
实际员工角色与捕获接通顺序见 [CREW_ACTOR_IMPLEMENTATION](CREW_ACTOR_IMPLEMENTATION.md)
和 [CREW_CAPTURE_IMPLEMENTATION](CREW_CAPTURE_IMPLEMENTATION.md)。
