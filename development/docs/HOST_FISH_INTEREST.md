# 两名成员附近的房主鱼区域

0.1.42-dev、协议8增加默认关闭的 `Network.ExperimentalHostFishAreas` 开发入口。
这项工作针对同一已加载场景中两名成员相距很远时的房主鱼生成和活动。
入口只在首次 Network Update 读取，修改后须重启；不自动改本机配置或安装插件。
原生挂钩、数组访问与实际远距离玩法尚未验证，不能据编译或 CLR/TCP 测试声称可以自由分头捕鱼。

## 区域与来源

房主维持两个人附近的区域，分别计算后合并。不会构造连接两人的大矩形，
也不会为了扩大活动范围移动真实玩家、镜头或鱼的生成中心。
收到的角色帧提供员工的位置观察；它不是可信原生员工、装备、氧气、投射物或命中权限。

成功接收角色包时冻结房间、握手绑定的成员编号和包序号，保留实际房主接收时间。
消费者使用原始帧副本，不使用角色显示的插值位置或远端时钟作为接收新鲜度。
真实 Host/Ready、当前 Main peer、房间、epoch、场景和成员必须持续一致。
Local test 不参与原生区域维护；暂停、换层、断线、换 peer、本地玩家更换或观察过期撤销该来源。
读取 Unity 对象只在已确认的 Unity 线程，读取前后复核实际 manager/player/transform/scene。

## 普通生成器

原普通生成协程中的位置查询和同一个 allocator 的中心查询形成有限同步范围。
只对一次距离查询返回代理中心，让原距离逻辑能考虑较近的成员。
原中心 getter 继续执行，其缓存回填与真实 `_cachedCenterPos` 保持原逻辑，
后续原选择、随机、保存身份、懒加载和生成流程仍由游戏执行。

首个窄范围只支持原最小生成距离为零的普通路径。
`MoveNext` 的 bool 表示协程继续，不能替换成“允许生成”；
`StopAlloc` 会停用、销毁并记录已生成状态，不能当区域开关。
Wave、未知或嵌套来源、强制生成、未匹配查询及失效窗口保留原结果。
同步包含不是完整原生数据流证明，Vector3 返回 ABI、浮点边界和所有生成路径仍待实机确认。

## 鱼活动与 LOD

只关联自然 `RequestManagement` 返回的真实鱼 target/LODData；
已核鱼自己的注册范围内，也可接受属于同一鱼子树的实际 target，未知共享 group 不猜归属。
在原 `AutoActivatorJob.Complete` 的匹配 job 已完成、原消费结果之前，
对已关联的鱼条目合并原房主区域与平移到员工位置的镜头区域。
保持原进入/离开迟滞、Z 裁剪及原鱼生命周期回调；不直接强制 SetActive 或改 reactive property。
其他管理对象、未知映射及未完成的 job 保持原结果。

NativeArray 的实际 buffer 身份通过已生成的直接字段读取，
元素只在匹配 job 完成之后经原 typed indexer 访问；不猜字段 offset 或直接写任意内存。
本批原消费列表顺序、实际 LODData 指针、target 位置和三个尺寸输入先冻结，
等待完成后与同一索引的请求及结果复核；未解析的 hash 字段不当成鱼身份。
编译引用不是原生数组布局、Harmony 值类型入口或 job 时序已通过的证据。
匹配 JobHandle 原调用正常返回且原异常为空才承认本批等待完成；
其他插件的挂钩顺序及未知写入仍未证明，失败不重派发原生修改。
原部分鱼避让依赖房主镜头的 `Renderer.isVisible`；0.1.43另接[员工附近的窄避让判断](HOST_FISH_VISIBILITY.md)。
这项源码补充尚未原生验证，活动区域和一次可见性候选仍不能证明远处 AI 完整等效。

## 验收与后续

真实双游戏需要分别验证：同层分开、远处鱼生成与游动、各自镜头可见性、
移动离开后活动撤销、身份保持、捕获移除、正常断线/返航/保存。
另一层尚未加载、场景边界或已卸载区域不由此入口解决，自由跨层仍需后续加载与生命周期桥。
远距离活动范围会增加房主模拟开销；中间无人区域不会仅因两人分开就整体启用。
现有鱼清单最多4096个实体，超过有界观察容量会报告不可用，不代表整片海洋无限生成或传输。
LOD 窄范围每批最多512行；进程最多4096个保留记录、32个 manager、24576个显式强引用 handle，
只允许一个保留 owner。65536/8192 的步骤配额计自产 primitive 与 guard，
不包含来源复合 getter 内部的全部原生调用；实际性能尚未测量。

完整 M3—M7 继续要求可信员工角色/装备/生存/投射物和房主命中，
每人独立产物、容量、重量和负重，员工逐项返航入仓，以及双端闭环和 GitHub 冷配置。
所有通用 WorldAuthority、CargoAuthority、GuestStateIsolated 和 NativePermission 保持 false。
